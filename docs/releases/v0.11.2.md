## v0.11.2

### 正常退出提示
- 修复一方执行 `quit / exit / bye` 后，另一方偶尔直接结束而没有显示“对方已正常结束会话”的竞态。
- 正常退出仍优先通过 `BYE` 控制帧通知对端；如果 QUIC 正常关闭先于 `BYE` 被读取，对端也会根据远端 QUIC application close code 0 识别为正常退出。
- 本地正常关闭不会被误判为“对方退出”，异常断网、超时等情况仍保留异常提示。

### 连接流程
- 保持 v0.11.1 的确定性双识别码流程：固定交换 `P2PF-INVITE-...` 和 `P2PF-REPLY-...` 后再开始真实 QUIC 建连。
- IPv6 仍然优先；如果 IPv6 被防火墙过滤或不可达，会自动回退 IPv4 / NAT 打洞。
- 不增加第三个识别码，不修改信令格式和协议版本，与 v0.11.1 保持兼容。

### 发布说明
- GitHub Release 文案会与 `docs/releases/v*.md` 同步，修订仓库内发布说明后不会再出现 Release 页面仍保留旧文案的情况。
