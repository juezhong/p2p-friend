## v0.11.4

### Linux arm64 / aarch64
- 新增 Linux arm64（aarch64）官方发布二进制：`p2p-friend-linux-arm64`。
- CI 增加 Linux arm64 交叉编译检查，确保每次变更都能构建该架构。
- Windows 发布仍保持 `amd64`，不新增 Windows arm64 构建。
- Linux amd64、macOS amd64 / arm64 的现有发布产物保持不变。

### 局域网
- 现有局域网直连能力保持不变。
- 同一局域网中的私网 IPv4 / IPv6 host candidate 会直接参与选路，成功时显示 `IPv4-LAN` 或 `IPv6-LAN`。
- 局域网直连不依赖 STUN，也不需要经过公网 NAT 打洞。
