- 清理 `network.go` 中残留的 WebRTC / ICE / DTLS / DataChannel 历史注释，明确当前网络栈是 UDP + STUN + QUIC/TLS 1.3。
- 在 QUIC candidate、IPv4 NAT 打洞、IPv6 stateful firewall 探测、路径竞争和 client/server 角色处补充中文设计注释。
- 解释 `InsecureSkipVerify` 与自定义 SHA-256 证书指纹 pinning 的关系，避免误认为关闭了远端证书校验。
