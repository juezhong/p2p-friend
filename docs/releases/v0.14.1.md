## v0.14.1

### 真正多 UDP Flow

- v0.14.0 的多 QUIC connection 仍共享同一个 UDP source port，因此虽然有独立 QUIC congestion state，但网络侧仍可能把它们识别为同一 UDP 5-tuple。
- v0.14.1 为额外 data stripe 优先创建独立 UDP socket/source port，使最多 4 条 data QUIC 形成不同 UDP 5-tuple。
- 目标 endpoint 仍复用主连接已经打通的地址，不重新执行 STUN、UDP punch 或显式端口映射。
- 独立 source port 失败时自动回退到 v0.14.0 的共享 UDP socket stripe，不影响主会话和连通性。

### 接收端乱序窗口

- 小文件保持约 64 MiB 窗口。
- 512 MiB 以上文件提升到约 128 MiB。
- 2 GiB 以上文件最高约 256 MiB。
- 窗口仍有硬上限，不会按文件大小无限增长。

### 可观测性

- `status` 增加每条 data QUIC 的本地/远端 UDP endpoint，便于确认是否真的使用不同 source port。

### 兼容性

- VERSION 更新为 0.14.1。
- Signal / ALPN / 应用协议仍为 v14，与 v0.14.0 保持 wire protocol 兼容。
