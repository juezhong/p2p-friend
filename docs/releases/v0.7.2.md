## v0.7.2

### 连接稳定性
- JOIN 端生成 ANSWER 后不再因为第一轮 QUIC candidate 失败立即退出。
- JOIN 会在完整等待窗口内持续重试 IPv6 / IPv4 candidate，允许创建方有足够时间复制并粘贴 ANSWER。
- UDP hole punching 在整个连接等待阶段持续运行，不再只发送短时间探测。

### 自适应 QUIC 发送
- Windows 不再固定为 2 lane / 64 KiB。
- 新增运行时自适应发送控制，根据 QUIC stream Write 的实际阻塞时间动态调节：
  - 1~4 条 active data lane
  - 32~256 KiB application chunk
  - 0~2 ms pacing
- 发送持续顺畅时逐步升档；出现明显阻塞或发送错误时自动降档。
- Linux 默认从高吞吐配置起步，遇到实际背压时同样可自动降档。
- 保留 4 条 QUIC data stream、offset WriteAt 和端到端 SHA-256 校验。

### 测试
- 新增“JOIN 先开始连接、HOST 延迟启动监听”的 QUIC 集成测试，覆盖手工复制 ANSWER 的等待场景。
- 新增自适应发送升档 / 降档测试。
