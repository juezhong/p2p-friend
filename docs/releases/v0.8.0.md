## v0.8.0

### 连接流程与交互
- 用户界面不再暴露 `HOST / JOIN / OFFER / ANSWER` 术语，统一改为“发起连接 / 加入连接 / 连接码 / 确认码”。
- 信令前缀统一为 `P2PF-...`，协议版本和信令类型放在码内部。
- 发起方生成连接码后立即启动 QUIC listener；不再等确认码粘贴后才开始监听。
- 加入方使用长生命周期连接管理器等待对端真正就绪，不把一次 candidate 尝试失败当成最终失败。
- UDP NAT punch 循环动态读取对端 candidate，确认码到达后立即生效。
- 只有最终连接超时时才建议交换“发起连接 / 加入连接”角色。

### 链路可见性
- 提示符和 `status` 显示实际链路类型：
  - `IPv6-DIRECT`
  - `IPv6-LAN`
  - `IPv4-DIRECT`
  - `IPv4-LAN`
  - `IPv4-NAT-PUNCH`

### macOS
- Release 新增 macOS Intel (`darwin-amd64`)。
- Release 新增 macOS Apple Silicon (`darwin-arm64`)。
- CI 同时交叉编译 Linux、Windows 与两种 macOS 架构。

### 保留
- QUIC 多 stream、自适应 lane/chunk/pacing。
- offset `WriteAt` 大文件传输。
- 发送前与接收落盘后的 SHA-256 校验。
- 远端文件系统浏览、Tab 补全和 `Ctrl-C` 取消传输。
