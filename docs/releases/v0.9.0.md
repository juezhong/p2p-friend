## v0.9.0

### 传输交互
- 修复实时进度与 SHA-256 校验输出挤在同一行的问题。
- 传输进度在校验开始前会完整结束当前行，最终校验与完成信息单独输出。
- 正常传输信息只显示在发起本次 `put` / `get` 的一端。
- 被动发送文件或被动接收文件的一端保持安静，避免异步日志打断正在输入的命令。
- 自适应 lane / chunk / pacing 调节改为静默运行，不再不断输出调参日志。

### 单传输仲裁
- 新增会话级传输租约。
- 同一 P2P 会话同一时刻只允许一个文件或目录传输任务。
- 任意一端都可以发起 `put` / `get`，但第二个同时发起的传输会被明确拒绝。
- 目录浏览、`status` 等控制命令不受文件传输租约限制。
- 传输结束、取消或失败后租约自动释放。

### status
`status` 现在会显示：
- 实际链路类型（IPv6-DIRECT / IPv4-NAT-PUNCH 等）
- QUIC / UDP / TLS 1.3
- QUIC 监听端 / 主动连接端
- 当前选中的本地 UDP endpoint
- 当前对端 UDP endpoint
- IPv4 / IPv6 socket 与监听 / 打洞状态
- 本机 STUN 映射
- 对端 candidate 类型
- QUIC control / data stream 数量
- 当前传输租约状态
- 当前发送自适应参数
- 本地 / 远端目录和覆盖策略

连通性检查、NAT 打洞、QUIC 握手和文件传输继续复用同一 UDP socket。

### 连接输出
- candidate / connection manager 的正常重试继续保持静默。
- 只有最终连接超时时才输出交换“发起连接 / 加入连接”角色的建议。

### 协议
- 内部协议升级到 v9。
- 用户可见连接码继续统一使用 `P2PF-...` 前缀。
