## v0.9.1

### Graceful shutdown
- `quit / exit / bye` 现在走正常会话关闭流程，不再把 QUIC application error code 0 当成传输异常。
- 本地主动退出会先发送 `BYE`，再清理活动传输、临时文件和会话状态，最后关闭 QUIC 与 UDP 资源。
- 对端收到正常退出后只显示“对方已正常结束会话”，不再打印 `Application error 0x0 ... session closed`。
- QUIC application close code 0、`net.ErrClosed`、EOF 等预期关闭错误会被统一识别并静默处理。

### Resource cleanup
- 关闭会话时取消所有活动 outbound transfer。
- 未完成接收会清理 `.part` 临时文件，并按原有取消逻辑回滚本次传输中新建内容。
- 清空会话级传输租约与自适应传输状态。
- 关闭 QUIC connection 后显式关闭 listener、transport 和程序创建的 UDP socket，确保端口及时释放。

### UX
- 本地主动退出显示正常结束提示。
- 对端正常退出显示正常结束提示。
- 非正常网络断开仍保留异常日志，不会被误吞。
